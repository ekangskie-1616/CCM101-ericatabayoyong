# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform that provides
computing, storage, networking, database, security, and other cloud services.

## Global Infrastructure

AWS provides cloud infrastructure through Regions and Availability Zones
located in different parts of the world.

## Cloud Management Console

The AWS Management Console is a web-based interface used to create,
manage, and monitor AWS cloud resources.

## Four Core Services

1. Amazon EC2 – Virtual servers for running applications.
2. Amazon S3 – Object storage for files and data.
3. Amazon VPC – Networking environment for AWS resources.
4. Amazon RDS – Managed relational database service.

## Three Advantages

1. Wide range of cloud services
2. Global infrastructure
3. Flexible scalability

## Typical Enterprise Use Cases

AWS can be used for web applications, databases, file storage,
backup, disaster recovery, enterprise systems, and large-scale applications.
