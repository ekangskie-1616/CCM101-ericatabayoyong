# Microsoft Azure Research

## Brief Overview

Microsoft Azure is Microsoft's cloud computing platform that provides
services for computing, storage, networking, databases, security,
artificial intelligence, and application development.

## Global Infrastructure

Azure provides cloud infrastructure through regions and availability
zones distributed around the world.

## Cloud Management Console

The Azure Portal is a web-based interface used to create, manage,
configure, and monitor Azure resources.

## Four Core Services

1. Azure Virtual Machines – Provides virtual machines in the cloud.
2. Azure Blob Storage – Provides object storage.
3. Azure Virtual Network – Provides cloud networking.
4. Azure SQL Database – Provides managed SQL databases.

## Three Advantages

1. Strong Microsoft integration
2. Enterprise security features
3. Global cloud infrastructure

## Typical Enterprise Use Cases

Azure is commonly used for Windows Server workloads, enterprise
applications, databases, Microsoft environments, hybrid cloud,
and cloud-based applications.
